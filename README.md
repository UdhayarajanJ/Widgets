# Resizable Widgets Dashboard

A dynamic Angular dashboard where users can add, resize, and manage multiple widgets in real time.

---

## Features

- Add multiple widgets dynamically  
- Resize widgets using drag handles  
- Drag & drop layout support  
- Responsive grid-based UI  
- Custom widget configuration  
- Scalable architecture  

---

## Tech Stack

- Angular  
- TypeScript  
- SCSS

---
